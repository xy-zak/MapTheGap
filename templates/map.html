citation this source's reference list contains that one — directed, so it always points back in time. Read from published reference lists via OpenAlex, with Semantic Scholar covering preprints.
shared vocabulary tag overlap of 0.50 or better — shared tags divided by all tags across both — on subject, question and approach. Drawn only where no citation exists, since a citation says strictly more.
position an output of the links, not the year: citations pull hard, vocabulary weakly, every source repels every other. Only who sits beside whom means anything — distance between far-apart groups does not. Vocabulary is drawn thin and faint, so a group joined only by dashes shares language but cites nothing. Distance is not a scale: there is one fixed arrangement, and it is the only one the physics offers.
cluster hulls communities found on the links alone, independently of the layout, each named by the most distinctive subject, question or approach tag its members share — the facets that built the links, with the prefix dropped. Select a source and every hull covering it turns solid and names itself — one sitting where two strands overlap names both. They are the cross-check: a hull that comes out long and tangled means the maths and the physics disagree, so do not believe that grouping.
