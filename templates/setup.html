01

Sync Zotero to zotero.org

The map reads your library from zotero.org rather than from the desktop app, so the desktop library has to sync there.

  1. No account yet? Create a free one.
  2. In Zotero, open Edit → Settings → Sync (on macOS, Zotero → Settings → Sync), sign in, and leave Sync automatically on.
  3. Wait for the first sync to finish (the green arrow at the top right stops spinning).

File sync and attachments don't matter here. Only item data is read.

02

Create an API key

  1. Open zotero.org/settings/keys/new and sign in.
  2. Name it something like MapTheGap.
  3. Under Personal Library, tick Allow library access. The map only reads, so Allow write access can stay unticked. Tick it only if you also use the Claude Code skills in this repo to file and tag papers, because those write to the library.
  4. Press Save Key and copy the key it shows: 24 letters and digits. Zotero shows it only once.
03

Link your Zotero database

The contact address is optional. OpenAlex and Semantic Scholar, the two services that supply reference lists, answer requests that include one faster and limit them less. It is sent only to those two services.

04

Build the map

Pulls the library, looks up every source's reference list, and draws the map. The first build is the slow one: Semantic Scholar allows about one request every five seconds, and everything it returns is cached, so later builds take seconds.
